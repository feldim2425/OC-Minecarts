Many people will already have noticed that this mod isn't beeing updated. And I won't upgrade this mod anytime soon.

Reasons:
- Despite OpenComputers and Railcraft beeing pushed to 1.12 a long time ago, development for those mods seem to have stalled as well.
- The way I would have written OC-Minecarts now is different (it was my first mod and one of my earliest Java projects, I have learned a lot since back then) I am not happy with the codebase anymore.
- The API has change A LOT since 1.7.10 I would need an entire rewrite and I failed multiple times trying to relearn and redo the whole project.
- Changes in both my personal life, the Minecraft modding world (Modloaders, APIs etc) haven't really helped my motivation. Haven't even played Minecraft in a long time.
